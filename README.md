# J.A.R.V.I.S. releases

Installers and the auto-update feed for J.A.R.V.I.S., a desktop assistant for Windows.

**Install:** download `JARVIS_<version>_x64-setup.exe` from the [latest release](https://github.com/GeorgeWebDevCy/jarvis-releases/releases/latest) and run it.
Installed copies update themselves from `latest.json` (signed installers).
